# 🚀 Complexity Analyzer AI

> A modern AI-inspired static code analysis web application that estimates **Time Complexity**, **Space Complexity**, identifies algorithms and data structures, and provides optimization suggestions — all running directly in the browser with **HTML, CSS, and JavaScript**.

![License](https://img.shields.io/badge/License-MIT-green)
![JavaScript](https://img.shields.io/badge/JavaScript-ES2025-yellow)
![HTML5](https://img.shields.io/badge/HTML5-orange)
![CSS3](https://img.shields.io/badge/CSS3-blue)
![Status](https://img.shields.io/badge/Status-Active-success)

---

## ✨ Features

- ⚡ Estimate Time Complexity
- 💾 Estimate Space Complexity
- 🧠 Detect common algorithms
- 📚 Detect common data structures
- 📊 Confidence Score
- 💡 Optimization Suggestions
- 📖 Detailed Explanation
- 🌙 Dark / Light Theme
- 📈 Interactive Charts
- 📂 Upload Source Code Files
- 📋 Copy Analysis Results
- 📱 Fully Responsive Design
- ⚙️ Runs Completely in Browser
- 🚫 No Backend Required
